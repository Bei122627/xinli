## 怎么看效果

**最简单的方式**：直接双击 `index.html`，就会在浏览器里打开。

> 情绪打卡功能也能正常用 —— 数据存在浏览器的 localStorage 里。
> 但注意：用 `file://` 直接打开时，某些浏览器对本地存储有限制。
> 如果打卡后刷新页面记录消失了，改用下面这种方式。

**推荐的方式（本地预览服务器）**：

```bash
# 在本文件夹下打开命令行，执行：
python -m http.server 8000
```

然后浏览器访问 `http://localhost:8000`。这样 localStorage 工作最稳定。

## 四个页面分别做什么

### 首页 `index.html`

不讲概念，只讲「此刻能做什么」：

- 今晚睡不着 → 躺满 20 分钟就起来、别看时间、4-7-8 呼吸
- 突然心慌喘不上气 → 脚踩地、说出 5 样东西、拉长呼气
- 不想社交 → 先只跟一个人说一句话、找「一起做事」的场合

最后有一段「什么情况建议尽快找人聊聊」的提示：持续两周以上的低落 / 睡眠食欲问题，或出现危险念头。

### 自助工具 `tool.html`

**这是整个网站唯一「活」的功能。**

用户每天给情绪打 1–5 分，可以写一句话。页面会自动做三件事：

1. 画出最近 14 次的情绪曲线
2. 生成统计提示（平均分、连续低分预警、星期几规律、状态是否在变好）
3. 列出历史记录

数据只存在用户自己的浏览器里，不上传任何服务器。

### 求助资源 `help.html`

做得最扎实的一页，包含：

- 紧急情况：120 / 110
- **全国统一心理援助热线 12356**（2025 年 5 月 1 日起全国开通，24 小时免费保密）
- 学校心理咨询中心的信息（**目前是示例，需要你改成真实的**）
- 「去心理咨询是不是说明我有病」「辅导员会知道吗」「该说什么」「不合适能换吗」「怕被同学看到」—— 五个最常见顾虑的解答

### 关于 `about.html`

说清能做什么、不能做什么、数据存在哪里、为什么不要真实信息，以及免责声明。

## 你需要自己改的地方

### 1. 学校心理咨询中心的信息（最重要）

打开 `help.html`，找到这一段替换成真实信息：

```html
<h3>XX 大学 学生心理健康教育与咨询中心</h3>
<span class="phone">0XXX-XXXXXXX</span>
<div class="meta">
  <strong>地点：</strong>XX 校区 XX 楼 X 层 X 室<br>
  <strong>开放时间：</strong>周一至周五 8:30–11:30，14:00–17:00<br>
  <strong>预约方式：</strong>电话预约 / 线上系统预约 / 直接到访<br>
  <strong>费用：</strong>在校生免费（一般每学期有次数上限）<br>
  <strong>单次时长：</strong>约 50 分钟
</div>
```

**建议直接跑一趟心理中心问清楚这几项。** 对同学来说，这个电话比全国热线有用得多。

### 2. 网站名字

现在是「心情树洞」，想改的话全站搜索替换即可（在每个 html 的 `<title>`、`.logo` 里）。

> ⚠️ 上线备案时，网站名**别带「心理」「健康」「咨询」「医疗」**字样，容易被要求补充资质材料。
> 「心情树洞」「校园树洞」这类中性名字更稳。

### 3. 联系方式

`about.html` 最后一节「联系我」里填上你的邮箱。

### 4. 配色（可选）

打开 `css/style.css`，最上面的 `:root` 里改几个颜色值，全站跟着变：

```css
--green: #4a9c7d;    /* 主色 */
--amber: #d99a4e;    /* 提醒色 */
--red: #c85a54;      /* 危机色 */
```

## 下一步：接后端

现在打卡数据存在浏览器里（`js/tool.js` 的 `loadData` / `saveData` 两个函数）。

等学完 Node.js，**只要把这两个函数换成 `fetch` 请求**，其他代码一行都不用动：

```js
// 现在（本地存储）
function loadData() {
  return JSON.parse(localStorage.getItem('moodRecords') || '[]');
}

// 以后（后端接口）
async function loadData() {
  const res = await fetch('/api/moods');
  return await res.json();
}
```

对应的数据表：

```sql
CREATE TABLE mood_records (
  id INT AUTO_INCREMENT PRIMARY KEY,
  user_id INT NOT NULL,
  mood_score TINYINT NOT NULL,
  note VARCHAR(200),
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
  INDEX idx_user_time (user_id, created_at)
);
```

详细的部署流程见同目录下的 `心理健康网站-建站手册.md`。

## 内容上的三条红线（改内容时请守住）

1. **量表结果绝不下诊断。** 可以说「你的分数落在某区间，建议去聊聊」，不能说「你有中度抑郁」。这是专业伦理，也是法律风险点。
2. **不做公开匿名留言墙。** 一旦有人在上面写下危险的话，你没有能力接住。
3. **不收真实身份信息。** 只让用户设昵称，不收姓名、学号、手机号。这样合规成本几乎为零。
